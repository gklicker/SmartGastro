# План тестирования SmartGastro (CLI)

Этот документ содержит тест-кейсы для проверки функциональности приложения через командную строку (`cli.py`).

## 1. Управление инвентарем (Agregar producto)

### Тест-кейс 1.1: Добавление нового продукта
*   **Действие:** Выбрать опцию `1`, ввести данные нового продукта.
*   **Ввод:**
    ```text
    1
    Empanada
    150
    100
    20
    ```
*   **Ожидаемый результат:** Сообщение `✓ Producto agregado:` с деталями продукта (Empanada, цена 150, запас 100, минимум 20).

### Тест-кейс 1.2: Обновление запаса существующего продукта
*   **Условие:** Продукт "Empanada" уже существует.
*   **Действие:** Выбрать опцию `1`, ввести то же имя и цену, подтвердить добавление запаса.
*   **Ввод:**
    ```text
    1
    Empanada
    150
    s
    50
    ```
*   **Ожидаемый результат:** Сообщение `✓ Stock actualizado:` с обновленным запасом (150).

### Тест-кейс 1.3: Попытка добавить продукт с другой ценой
*   **Условие:** Продукт "Empanada" существует с ценой 150.
*   **Действие:** Попробовать добавить "Empanada" с ценой 200.
*   **Ввод:**
    ```text
    1
    Empanada
    200
    ```
*   **Ожидаемый результат:** Ошибка `✗ 'Empanada' ya existe con un precio diferente ($150.00).`

---

## 2. Управление событиями (Crear evento)

### Тест-кейс 2.1: Создание нового события
*   **Действие:** Выбрать опцию `4`, ввести данные события.
*   **Ввод:**
    ```text
    4
    Lollapalooza
    Hipódromo de San Isidro
    2026-03-20
    -34.4833
    -58.5167
    ```
*   **Ожидаемый результат:** Сообщение `✓ Evento creado:` с названием события и информацией о погоде (если API доступен).

---

## 3. Регистрация продаж (Registrar una venta)

### Тест-кейс 3.1: Успешная продажа
*   **Условие:** Существует событие "Lollapalooza" и продукт "Empanada" (запас 150).
*   **Действие:** Выбрать опцию `2`, указать событие и продукт.
*   **Ввод:**
    ```text
    2
    Lollapalooza
    Empanada
    10
    (нажать Enter на пустом поле Producto)
    ```
*   **Ожидаемый результат:**
    1.  Сообщение `✓ Venta registrada:`.
    2.  Запас "Empanada" в инвентаре уменьшился до 140.

### Тест-кейс 3.2: Продажа при недостаточном запасе
*   **Условие:** Продукт "Empanada" имеет запас 140.
*   **Действие:** Попытаться продать 200 штук.
*   **Ввод:**
    ```text
    2
    Lollapalooza
    Empanada
    200
    (Enter)
    ```
*   **Ожидаемый результат:** Сообщение об ошибке `✗ Error: Stock insuficiente para 'Empanada' (disponible: 140)`.

### Тест-кейс 3.3: Оповещение о низком запасе
*   **Условие:** Продукт "Empanada" имеет минимум 20. Текущий запас 25.
*   **Действие:** Продать 10 штук.
*   **Ввод:**
    ```text
    2
    Lollapalooza
    Empanada
    10
    (Enter)
    ```
*   **Ожидаемый результат:** После подтверждения продажи появится секция `Alerta de stock bajo:` со списком продуктов.

---

## 4. Просмотр отчетов

### Тест-кейс 4.1: Просмотр инвентаря
*   **Действие:** Выбрать опцию `3`.
*   **Ожидаемый результат:** Список всех продуктов с текущим запасом и ценами.

### Тест-кейс 4.2: Просмотр истории продаж
*   **Действие:** Выбрать опцию `5`.
*   **Ожидаемый результат:** Список зарегистрированных продаж с указанием события, даты и итоговой суммы.
